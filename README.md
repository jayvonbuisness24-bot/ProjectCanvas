# Project Canvas

> **Project Canvas** is a competitive, round-based paintball FPS being developed for Roblox with a focus on skill, fairness, player expression, and long-term maintainability.

---

## Vision

Project Canvas aims to become the premier competitive paintball experience on Roblox.

Every design decision follows these principles:

* Skill determines outcomes.
* Cosmetics never provide gameplay advantages.
* Systems are designed to scale.
* Players have extensive control over their experience.
* Every feature must strengthen the game's identity.

---

# Core Pillars

## 🎯 Skill First

Players win through aim, positioning, communication, and decision-making.

---

## ⚖️ Fair Play

Everyone starts with equal access to competitive gameplay.

No pay-to-win mechanics.

---

## ⚡ Fast Action

Minimal downtime.

Quick transitions.

Rounds remain engaging from start to finish.

---

## 🎨 Identity

Every mechanic, cosmetic, and system should feel like it belongs to Project Canvas.

---

## 🎛 Player Ownership

Players can personalize nearly every aspect of their experience without affecting competitive balance.

Examples include:

* Crosshair editor
* HUD customization
* Audio settings
* Camera settings
* UI scaling
* Accessibility options

---

# Current Development Stage

## Milestone 1 — First Playable

The current objective is to create a minimal but fully playable prototype.

Requirements:

* Player movement
* First-person camera
* Viewmodel
* One semi-auto marker
* Paintball hit detection
* Paint splatter effects
* One-hit elimination
* Round system
* Team spectating
* Final Play replay
* Regroup phase

Nothing else will be developed until this milestone is complete and enjoyable to play.

2. Documentation update
3. Feature specification
4. Claude implementation
5. Roblox Studio testing
6. Code review
7. Refinement
8. Merge

No feature should be implemented without first being documented.

---

# Coding Philosophy

* Server-authoritative gameplay
* Modular architecture
* Clear separation of client, server, and shared code
* Readable, maintainable code
* Security before convenience

---

# Monetization Philosophy

Project Canvas will never sell competitive advantages.

Monetization is focused on player expression through cosmetic items, optional conveniences, and future content that respects competitive integrity.

---
